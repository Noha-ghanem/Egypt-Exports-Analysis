# Egypt Export Analysis & Revenue Potential

## Project Overview
This project analyzes Egypt's agricultural export performance (2014–2024), global market demand, and future growth opportunities using Power BI through a multi-page interactive dashboard.

## Tools & Technologies
- Microsoft Power BI (DAX, Data Modeling, What-If Parameters)
- Data Cleaning & Transformation
- Data Visualization

## Project Files
- Power BI Dashboard (.pbix)
- Dataset Files
- Dashboard Screenshots

## Dashboard Preview
Screenshots of the 4 dashboard pages (`Egypt Export Overview`, `Global Demand & Target Markets`, `Export Opportunity Matrix`, and `Revenue Potential Simulator`) are available in the repository.

## Key Analysis
- **Export Overview:** Tracking total export values, growth trends, destination counts, and volume vs. price effects.
- **Global Demand:** Evaluating global import market sizes and export opportunities across countries.
- **Opportunity Matrix:** Identifying high-potential target products and partner countries.
- **Revenue Potential Simulator:** Forecasting export revenue growth using multiple growth scenarios.
